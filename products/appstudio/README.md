# appstudio

App Studio: [opencode](https://opencode.ai)'s web UI (`opencode serve`) over a
persistent workspace, in an image with Python, Node, uv, the `freepod` CLI and
its `deploy-to-freepod` skill. Experimental; not in the catalog.

| Component | Object(s)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|-----------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| opencode  | StatefulSet `<release>-app` (one replica), Service `<release>-app` `:80` → `$STUDIO_PORT` (4096)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Storage   | PVC `workspace` → `/workspace`, PVC `opencode` → `/root/.local/share/opencode` (sessions, provider credentials)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| SSH key   | Secret `<release>-ssh`: an ECDSA key generated on first install and kept across upgrades, installed as `~/.ssh/id_ecdsa`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| SFTP      | The platform's SSH sidecar with a read-only volume root of the apps directory (`appsDir`) only, and its Service `<release>-ssh`; the rest of the workspace (credentials, opencode's config) is not mounted                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Preview   | Ingress `<release>-preview` at `preview-<first label>.<rest of the host>` → port 8080, for whatever the agent runs there; while nothing listens, the chrome's `preview-down.html` waits for it. Wildcard-certificate hosts only                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Sign-in   | Middlewares `<release>-strip-identity` and `<release>-app-auth` ahead of everything on both Ingresses: Sign in with Freepod, the owner's account only. The template must set `auth.enabled: true` as a system value; the chart refuses to render otherwise |
| Password  | Secret `<release>-opencode`, generated on first install and kept across upgrades, as `OPENCODE_SERVER_PASSWORD`. Middleware `<release>-opencode-auth`, after app-auth on the studio Ingress only, sends it as Basic auth, so the browser never sees it; the chrome's probe drops it before the preview port                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Ingress   | `<release>-ingress`, only once the reconciler injects a hostname. A fresh load of `/` redirects to the chrome at `/.appstudio/`. `/sw.js` is the chrome's too: a service worker that takes over from opencode's, whose navigation fallback would otherwise answer `/` and `/.appstudio/` with opencode's own page. No other origin may frame it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Chrome    | Container `chrome` (nginx, `chromeImage`) serving `chart/files/` from ConfigMap `<release>-chrome`, with the apps directory, `platformUrl` and the preview URL rendered into the page rather than read from its URL: a bar with a link back to Freepod, a link to App Studio's docs there, a New project button and a Preview button over opencode in an iframe. Before opencode loads, the chrome adds every app to opencode's project list in the browser, through opencode's file API; New project runs `appstudio-new-app` through opencode's terminal API and reloads opencode on its Home with the new project selected. The Preview button lights up while `/.appstudio/probe`, a proxy to the preview port, gets an answer, and opens the preview in its own window. On a browser's first visit the chrome opens a session in the first app with an example prompt typed in. Page edits need a chart release, not an image |

`appstudio-start` (`image/bin/`) prepares the workspace on every start and runs
`opencode serve` from the first app:

| Path                                                 |                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `/workspace/apps/<name>`                             | One app per git repository, each its own opencode project. The first, `app`, always exists; `appstudio-new-app <name>` makes the others. Each is an empty repository until the agent copies the starter in. `appstudio-app` names the app of the current directory or worktree                                                                                                                                                                                   |
| `/opt/appstudio/template`, `/opt/appstudio/examples` | The starter app (`image/template/`) and a reference app built on it (`image/examples/`), read-only                                                                                                                                                                                                                                                                                                                                                               |
| `/workspace/trees`                                   | opencode's worktrees, through a link from its data directory                                                                                                                                                                                                                                                                                                                                                                                                     |
| `/workspace/.config`                                 | `XDG_CONFIG_HOME`: opencode's user config and skills, git's config, the freepod CLI's credentials and keys                                                                                                                                                                                                                                                                                                                                                       |
| `/etc/opencode/opencode.json`                        | opencode's managed config, which the user's cannot override                                                                                                                                                                                                                                                                                                                                                                                                      |
| `/opt/appstudio/AGENTS.md`                           | The agent's instructions (`image/AGENTS.md`), loaded through the managed config's `instructions`                                                                                                                                                                                                                                                                                                                                                                 |
| Playwright MCP                                       | `@playwright/mcp` with Chrome for Testing in `/opt/ms-playwright`, registered as `playwright` in the managed config (headless, in-memory profile, closed after 10 minutes without a browser call); the chart gives `/dev/shm` 512 Mi                                                                                                                                                                                                                             |
| `appstudio-reaper`                                   | Started beside opencode, restarted if it exits. Once no browser and no agent activity have been seen for 30 minutes, stops what the agent left running and disconnects the Playwright MCP servers; reconnects them and restarts the preview when a browser returns. `appstudio-reaper plan` shows what it would stop. Logs to the container's output and `/tmp/appstudio-reaper.log`; in Loki, `{app="appstudio", container="opencode"} \|= "appstudio-reaper:"` |

For local development the image carries PostgreSQL 18 and Garage (Freepod's
S3), neither started. `eval "$(dev-postgres)"` and `eval "$(dev-s3)"` start one
if needed and export the variables Freepod injects into a deployed app, with a
database and a bucket of the current app's own, named after it. `dev-app` runs the current
app's dev server in the background on the preview port with both, stopping
whatever held the port: one app is in the preview at a time.

The reaper tells a browser by an established connection to opencode's port
from outside the container (the web UI holds `GET /api/event` open), agent
activity by `session.*` events on that stream (`session.execution.*` for busy)
and, before suspending, by `GET /api/session/active`; it stops and restarts MCP
servers with `POST /api/experimental/mcp/<name>/disconnect` and `connect`. The
chrome lists apps with `GET /api/fs/list`, runs `appstudio-new-app` with
`POST /api/pty`, and writes opencode's project list and first draft tab into
browser storage. An opencode upgrade has to keep these.

## Image

`image/`, versioned by `image/VERSION`, never re-pushed. The `freepod` CLI is
installed from the repository's `cli/`, so build from the repository root:

```bash
docker buildx build --platform linux/amd64 --push \
  --build-context freepod-cli=cli \
  -t ghcr.io/erikvanzijst/freepod/appstudio:$(cat products/appstudio/image/VERSION) \
  products/appstudio/image
```

Then point `image` in `chart/values.yaml` at it, bump the chart and publish it
with `./scripts/publish-charts.sh appstudio`.
