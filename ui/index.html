Freepod

Freepod is an EU-hosted cloud with two separate uses. To get an existing app for everyday use, such as photo storage, use Freepod Apps on the website. To deploy a project of your own, use Freepod for Developers and the freepod command-line client.

Freepod Apps

For anyone who wants a private alternative to a cloud service, with no technical knowledge needed. Create an account, pick an app from the catalog and launch it. Freepod installs, runs and updates it. See getting started.

  • Photos: Immich, PhotoPrism
  • Files: Nextcloud
  • Passwords and passkeys: Vaultwarden
  • Chat: Matrix
  • Team collaboration: Mattermost
  • Forums and communities: Discourse, Lemmy
  • Knowledge and wikis: BookStack, Docmost
  • Project management: OpenProject

Freepod for Developers

For code you wrote yourself, by hand or with a coding agent. The freepod client builds a container from your source and puts it live on its own hostname. Install it with any one of:

uv tool install freepod
pip install freepod
brew install erikvanzijst/tap/freepod

If you use a coding agent, install the skill that teaches it how to build and deploy for Freepod:

freepod skill install

Deploy from the project directory. freepod login needs a person at a browser.

freepod login
freepod init
freepod deploy

Read more in Freepod for developers and the coding agents guide.
