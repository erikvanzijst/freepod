Freepod

Private alternatives to the cloud services you use every day, for your photos, files, passwords and chats. Each app runs in a pod of its own, hosted in the EU.

Deploying your own project to Freepod

Deployments use the freepod command-line client. Install it with any one of:

uv tool install freepod
pip install freepod
brew install erikvanzijst/tap/freepod

Then add the skill that teaches your coding agent how to build and deploy for Freepod, sign in, which needs a person at a browser, and deploy from the project directory:

freepod skill install
freepod login
freepod init
freepod deploy

Read more in Freepod for developers and the coding agents guide.
