Mattermost is team chat with channels, direct messages and file sharing.

## Settings

| Setting | Meaning |
| --- | --- |
| Hostname | The app's address |
| Site name | Name shown in Mattermost and on its login screen |
| Site description | Text shown above the login form |
| Timezone | Mattermost's timezone, such as `Europe/Amsterdam` |

## First sign-in

The first account created in Mattermost becomes its system administrator. Open the app soon after launching it:

1. Select **Open** on the app's card, and select **View in Browser**.
2. Enter an email address, a username and a password, and select **Create account**.
3. Follow Mattermost's steps to create a team.

Invite other people from Mattermost.

## Desktop and mobile apps

Install the Mattermost apps from [mattermost.com/apps](https://mattermost.com/apps/) and enter `https://<hostname>` as the server URL.

## File access

[SFTP](../file-access.md) shows Mattermost's data folder, including uploaded files, read-only.

## Email

Mattermost sends email, such as notifications and invitations, from `mattermost@freepod.eu`. See [Email](../email.md).
