App Studio is a coding agent in your browser, built on [OpenCode](https://opencode.ai). You describe an app, the agent writes and runs it, and you try it out in a live preview. When it works, the agent publishes it on Freepod as an app of its own.

## Settings

| Setting | Meaning |
| --- | --- |
| Hostname | App Studio's address |

## Signing in

Only your own Freepod account can open App Studio and its preview. Anyone else who signs in sees a page saying they have no access.

The first time a browser opens App Studio, it starts a new session with an example prompt typed in. Press Enter to watch the agent build and publish a small app, or replace the prompt with your own.

## Several apps

One studio holds any number of apps, each a project of its own in OpenCode with its own sessions. App Studio starts with one, `app`.

**New project** at the top right asks for a name and creates the next one. OpenCode then shows its Home with the new project selected: start a session there with **New session**. To switch apps, open Home (the grid button at the top left) and select a project. A session always works on the app it was started in.

Each app is published separately, as an app of its own on your account.

## The preview

The **Preview** button at the top right of App Studio lights up while the app the agent is building is running, and opens it in a window of its own. The preview updates as the agent changes the code. While nothing is running, the preview window shows a page that waits for the app.

The preview shows one app at a time: when the agent runs an app, the one that was running stops.

Each app has its own local database and file storage for the preview, which start empty again whenever App Studio restarts. A published app has its own, separate ones.

## When you're away

The agent keeps working when you close App Studio's tab. Once no tab has had App Studio open for 30 minutes and the agent has finished, App Studio stops what is running for the preview: the app, its database and file storage, and the agent's browser. Their data is kept.

When you open App Studio again, the app that was in the preview starts again within seconds. Other apps you had running are not restarted.

Programs you started in the terminal keep running as long as that terminal is open.

## Publishing

Ask the agent to publish the app. The first time, it signs in to Freepod with your account: it shows a link and a code, and you approve the sign-in in your browser.

Each published app is a separate app on your account, with its own address, and appears in your dashboard next to your other apps. Published apps are billed by usage; see [Plans and billing](../plans-and-billing.md). App Studio itself does not change when you publish.

### Secrets

Passwords and API keys your app needs do not belong in the conversation. Type `/terminal` in the message box to open a terminal, and set them on the published app there, from the app's folder:

```bash
cd /workspace/apps/app
freepod var set API_KEY --secret
```

## Models

App Studio starts with OpenCode's free models. To use another model, connect a provider in OpenCode's settings with an API key from that provider.

### Your own models

To use your own locally hosted models, make sure your inference server (e.g. `llama.cpp` or `Ollama`) is accessible over the public internet and then configure it in OpenCode's settings -> Providers -> Custom provider.

Unfortunately, OpenCode's settings UI cannot configure everything a custom provider's model may need, such as its context size or reasoning effort. For those, edit OpenCode's configuration file in the terminal: `vim /workspace/.config/opencode/opencode.jsonc`. It is kept when App Studio restarts, and OpenCode merges it with App Studio's own settings. For example, a self-hosted OpenAI-compatible server with a reasoning model that also reads images:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "disabled_providers": [],
  "provider": {
    "deprutser": {
      "name": "De Prutser",
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://ai.deprutser.be/v1"
      },
      "models": {
        "qwen3.8-27b-q4": {
          "name": "qwen3.8-27b-q4",
          "reasoning": true,
          "variants": {
            "medium": { "reasoningEffort": "medium" },
            "low":    { "reasoningEffort": "low" },
            "xhigh":  { "reasoningEffort": "xhigh" }
          },
          "limit": {
            "context": 200000,
            "output": 16000
          },
          "modalities": {
            "input": ["text", "image"],
            "output": ["text"]
          }
        }
      }
    }
  }
}
```

OpenCode reads the file when it starts. To apply your changes, run `pkill -x opencode` in the terminal: App Studio restarts, which takes a few seconds, and the preview's local databases and file storage start empty again. See OpenCode's [configuration](https://opencode.ai/docs/config/) and [providers](https://opencode.ai/docs/providers/) documentation for every setting.

## Your code

Each app is a git repository in App Studio, in `/workspace/apps/<name>`. The terminal has git, vim, Node.js, Python and the PostgreSQL client, and runs as root.

[SFTP](../file-access.md) shows a folder per app, read-only, to copy files out of App Studio.

Sharing a session as a public link is not available.
