PhotoPrism is a photo library that indexes, tags and organizes photos and videos.

## Settings

| Setting | Meaning |
| --- | --- |
| Hostname | The app's address |
| Username | The name you sign in with. Cannot be changed later. |
| Password | The password of your account |

The username and password are used once, when the app first starts. To change the password later, use PhotoPrism's own settings. Changing it with **Edit** afterwards has no effect.

## First sign-in

1. Select **Open** on the app's card.
2. Sign in with the username and password from the settings.

Your account is PhotoPrism's administrator. Add other users from PhotoPrism's settings.

## File access

[SFTP](../file-access.md) shows the originals folder, which holds the uploaded photos and videos, read-only.

## Email

PhotoPrism does not send email.
