# Getting help

Email [support@freepod.eu](mailto:support@freepod.eu).

Include:

- the hostname of the app or deployment;
- what you did, what you expected, and what happened instead;
- any error message, exactly as shown;
- for developer deployments, the output of the failing `freepod` command and, if relevant, `freepod releases`.

Do not send passwords, master passwords, registration tokens or other secrets.

For questions about using an app itself, such as Nextcloud or Immich, its own documentation is linked from the [product guides](/apps/products).
