# Automatic updates

Freepod keeps apps up to date. New versions of each app, including security fixes, are installed automatically and promptly after they are published. You do not install updates, and they cannot be postponed or skipped.

- Freepod installs stable releases only. Pre-releases, such as betas and release candidates, are not installed.
- While an update is installed, the app restarts and may be unavailable for a short time.
- Updates can change the app's features or appearance. The app's own release notes, linked from the [product guides](/apps/products), describe what changed.
