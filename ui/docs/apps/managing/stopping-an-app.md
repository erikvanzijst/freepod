# Stopping an app

Stopping an app takes it offline without deleting anything. A stopped app does not run, and all its data, accounts, hostname and settings are kept.

1. Select the app on the dashboard to expand its row, and select **Stop**.
2. Select **Stop app** to confirm.

The app shows **Stopping** while it shuts down, then **Stopped**. While it is stopped, visitors to its address see a page saying the app is stopped.

## Starting an app

Select the stopped app on the dashboard to expand its row, and select **Start**. The app shows **Starting** until it runs again, which usually takes a minute or two.

A stopped app runs again only when you start it. [Automatic updates](automatic-updates.md) are still installed while it is stopped, and the new version first runs when you start the app.

## Good to know

- A stopped app does not charge you for any CPU or memory, only the for the storage it might have in use. 
- Only an app that is running normally can be stopped or started. An app that shows **Needs attention** cannot; see [Settings](settings.md) or contact support.
- Stopping an app does not cancel its subscription. To stop paying for an app, [delete it](deleting-an-app.md).
