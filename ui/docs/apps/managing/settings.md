# Settings

Each app has settings, entered when it is launched: at least its [hostname](hostname.md), and for some apps a few more, such as an admin email address. The [product guides](/apps/products) describe each app's settings.

To change them, select **Edit** on the app's card, change the values, and select **Update**. The app restarts with the new settings; it may be unavailable for a short time. **Edit** is available while the app's status is `ready`.

The plan cannot be changed from the dashboard. To change it, contact [support@freepod.eu](mailto:support@freepod.eu).
