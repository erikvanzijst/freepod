# Deleting an app

1. Select **Delete** on the app's card.
2. Type the app's hostname to confirm, and select **Delete**.

Deleting an app permanently deletes all its data: files, photos, messages, accounts and settings stored in it. **Freepod cannot restore a deleted app.** Download anything you want to keep first; see [Your data](../your-data.md).

The hostname becomes available again once the deletion has finished.

For questions about billing for a deleted app, contact [support@freepod.eu](mailto:support@freepod.eu).
