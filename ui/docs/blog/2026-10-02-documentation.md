Freepod's documentation is available at [freepod.eu/docs](/).

<!-- truncate -->

It has two sections:

- [Using apps](/apps): launching and managing apps from the catalog, custom domains, file access, and a guide per app.
- [Developers](/developers): deploying your own code with the `freepod` command-line client, the runtime contract, storage, authentication, and the CLI reference.

Questions and corrections: [support@freepod.eu](mailto:support@freepod.eu).
